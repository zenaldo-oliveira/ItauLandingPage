# Itaú Landing Page

Landing page inspirada na identidade visual e na experiência digital do Itaú, desenvolvida como projeto de estudo e prática em desenvolvimento frontend.

> **Aviso:** este projeto é independente e não possui vínculo oficial com o Itaú.

## Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar a criação de interfaces modernas, responsivas e orientadas à experiência do usuário.

A proposta é reproduzir, de forma independente, elementos de uma experiência bancária digital, utilizando componentes visuais, seções comerciais e layouts adaptados para diferentes dispositivos.

## Objetivos

- Praticar desenvolvimento frontend
- Trabalhar com layouts responsivos
- Desenvolver interfaces modernas
- Explorar componentes reutilizáveis
- Melhorar conhecimentos em HTML, CSS e JavaScript
- Trabalhar conceitos de UI/UX

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Layout responsivo
- Seções de destaque
- Navegação
- Cards e componentes visuais
- Botões e interações
- Adaptação para desktop e mobile
